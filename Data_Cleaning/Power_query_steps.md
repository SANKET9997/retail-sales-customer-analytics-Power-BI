# Data Cleaning & Transformation — Power Query

## Overview

The raw retail sales dataset was imported into Power BI from an Excel workbook and prepared using Power Query before building the data model and dashboard.

## Tables Processed

The dataset contains four main tables:

- Sales
- Customers
- Products
- Date

## Sales Table

Power Query steps:

1. Source
2. Navigation
3. Promoted Headers
4. Changed Column Type

The column data types were validated to ensure that text, numeric, and date fields were correctly recognized by Power BI.

## Data Quality Approach

The main data preparation activities were:

- Promoting the correct row as column headers
- Validating column data types
- Ensuring date fields were recognized correctly
- Ensuring numerical fields were recognized correctly
- Preparing the tables for relationships and DAX calculations

## Output

The prepared tables were loaded into Power BI and used to create the data model and interactive dashboard.
